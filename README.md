# JanDós — Приют для животных

Веб-приложение для приюта JanDós: поиск дома для питомцев, пожертвования, волонтёрство, программа передачи животных и полнофункциональная административная панель.

---

## 🚀 Быстрый старт

```bash
# 1. Установка зависимостей
npm install

# 2. Настройка окружения
cp .env.example .env

# 3. Запуск приложения
npm run dev
```

Приложение будет доступно по адресу: **http://localhost:3000**

---

## 📋 Системные требования

- **Node.js** версии 18 или выше
- **npm** (идёт в комплекте с Node.js)

Проверить версии:
```bash
node -v
npm -v
```

## 🛠 Стек технологий

### Frontend
- **React 19** — библиотека для построения UI
- **Vite** — сборщик и dev-сервер
- **Tailwind CSS v4** — утилитарный CSS-фреймворк
- **Framer Motion** — анимации
- **Recharts** — графики и диаграммы
- **Lucide React** — иконки

### Backend
- **Express.js** — веб-фреймворк
- **better-sqlite3** — SQLite база данных
- **JWT** — аутентификация
- **tsx** — выполнение TypeScript

### Инструменты
- **TypeScript** — типизация
- **ESLint** — линтинг

## ⚙️ Настройка переменных окружения

Скопируйте файл-пример и при необходимости отредактируйте:

```bash
cp .env.example .env
```

Содержимое `.env`:
```env
JWT_SECRET=your_jwt_secret_here   # Секретный ключ для JWT (любая строка)
PORT=3000                          # Порт сервера (по умолчанию 3000)
```

## 🎯 Основной функционал

### Для посетителей
- Просмотр питомцев с фильтрами и поиском
- Подача заявки на усыновление
- Пожертвования (разовые и подписки)
- Просмотр новостей приюта
- Информация о программе "Найти дом"

### Для волонтёров
- Запись на смены
- Просмотр расписания
- Отметка о передаче вещей

### Для администраторов
- **Дашборд** — статистика и аналитика
- **Питомцы** — добавление, редактирование, удаление
- **Новости** — управление публикациями
- **Сборы** — создание сборов средств
- **Заявки** — обработка заявок на усыновление
- **Волонтёры** — управление сменами и слотами
- **Пользователи** — управление ролями и блокировка
- **CMS** — редактирование страниц и футера
- **Медиа** — загрузка и управление файлами

- `users` — пользователи

- `audit_logs` — журнал действий
- И другие...

## 🐛 Отладка

При возникновении проблем:

1. Проверьте версию Node.js: `node -v` (должна быть 18+)
2. Удалите `node_modules` и переустановите: `rm -rf node_modules && npm install`
3. Проверьте права на папку `uploads/` для загрузки файлов
4. Проверьте логи в консоли браузера и терминала
