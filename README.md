# JanDós — Приют для животных

Веб-приложение приюта JanDós: адопция питомцев, пожертвования, волонтёрство и административная панель.

## Стек

- **Frontend:** React 19 + Vite + Tailwind CSS v4
- **Backend:** Express.js + better-sqlite3
- **Auth:** JWT
- **Runtime:** Node.js (tsx)

---

## Запуск локально

### 1. Требования

- [Node.js](https://nodejs.org/) версии **18 или выше**
- npm (идёт в комплекте с Node.js)

Проверить версию:
```bash
node -v
npm -v
```

### 2. Установка зависимостей

После распаковки архива перейдите в папку проекта и установите зависимости:

```bash
npm install
```

### 3. Настройка переменных окружения

Скопируйте файл-пример и при необходимости отредактируйте его:

```bash
cp .env.example .env
```

Содержимое `.env`:
```env
JWT_SECRET=your_jwt_secret_here   # секретный ключ для JWT (можно любую строку)
PORT=3000                          # порт сервера (по умолчанию 3000)
```

### 4. Запуск

```bash
npm run dev
```

Приложение будет доступно по адресу: **http://localhost:3000**

> База данных (`jandos.db`) создаётся автоматически при первом запуске. Тестовые данные (питомцы, новости, fundraisers) также заполняются автоматически.
